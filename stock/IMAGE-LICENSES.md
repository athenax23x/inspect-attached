## Before going live with third-party products

1. Get the owner's written approval to resell each brand.
2. Replace each placeholder with a licensed photo from the brand (or take an
   original photo of the stocked item). Brand press images are usually only
   cleared for dealer use — confirm terms per brand.
3. Update this file with the license source for every new image.
4. Set the product's stock count only after the image is final.
